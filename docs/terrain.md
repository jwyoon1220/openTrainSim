# 지형 생성 (terrain.json)

openBVE 노선은 선로 옆 오브젝트와 배경 그림만 있고 지형이 없습니다. 노선이 지도의 어디에 있는지만 알려 주면, 실제 표고 자료(DEM)로 선로 주변 지형을 만듭니다. 터널과 갱구, 땅깎기와 흙쌓기, 고가 아래 골짜기도 함께 만듭니다. 노선 파일과 오브젝트는 고치지 않습니다.

## 쓰는 법

노선 파일 옆에 `<노선 파일 이름>.terrain.json`을 둡니다(예: `KTX123.csv` → `KTX123.terrain.json`). `--terrain <파일>`로 직접 지정할 수도 있고, `--terrain none`이나 설정 파일의 `[terrain] enabled = 0`으로 끕니다.

```json
{
  // 노선 위치 ↔ 지도 좌표. 역 이름(일부만 써도 됨)이나 역 번호, 또는 "track": 거리정(m)
  "anchors": [
    { "station": "seoul",     "lat": 37.5547, "lon": 126.9707 },
    { "station": "daejeon",   "lat": 36.3326, "lon": 127.4342 },
    { "station": "busan",     "lat": 35.1150, "lon": 129.0416 }
  ],
  "width": 1500
}
```

기준점이 하나면 그 지점에서 선로가 향하는 방위 `"heading"`(도, 북 0·동 90)을 함께 줍니다.

```json
{ "anchors": [ { "track": 0, "lat": 37.5547, "lon": 126.9707 } ], "heading": 200 }
```

처음 실행할 때 필요한 DEM 타일을 받아 캐시(리눅스 `~/.cache/openTrainSim/dem`, Windows `%LOCALAPPDATA%\openTrainSim\cache\dem`)에 저장합니다. 이후로는 인터넷 없이도 동작합니다. 경부고속선 426 km를 폭 1.5 km로 만들면 타일 500장 정도(약 20 MB)를 처음에 한 번 받습니다. 다운로드에는 `curl`을 씁니다(Windows 10 이상에 기본 포함).

## 기준점은 많을수록 좋습니다

openBVE 노선의 평면 선형은 실제 선형과 다릅니다. 기준점 사이는 회전·축척 변환 하나로 맞추므로, 노선이 크게 휘어 가는 구간에서 기준점이 적으면 실제 선로에서 벗어난 자리의 지형을 가져옵니다. 그러면 실제로는 평지인데 산을 지나 터널이 생기는 식입니다. **역마다 기준점을 하나씩** 주는 것이 가장 쉽습니다. 기준점 사이의 노선 길이와 지도상 직선 거리가 10% 넘게 다르면 로그에 경고(`anchors i-j scale ...`)가 나옵니다. 그런 구간에는 기준점을 더 넣으세요.

높이도 맞춥니다. 기본은 선로를 따라 `verticalWindow`(8 km) 구간의 표고 중앙값에 선로를 맞추는 방식입니다. 큰 경사는 따라가고, 언덕(터널·땅깎기)과 골짜기(교량·흙쌓기)는 그대로 남습니다. 기준점에 `"elevation"`(그 지점의 레일 표고, m)을 적으면 그 값을 쓰고, 기준점 사이는 선형 보간합니다.

## 선로 주변을 만드는 방식

- **노반**: 선로 양쪽 `formation.width`(기본 8 m)를 레일보다 `formation.depth`(0.5 m) 낮게 평평하게 만듭니다. 선로에서 `formation.objectWidth`(60 m) 안에 노선 오브젝트(다른 선로, 승강장, 전철주, 건물 등)가 있으면 그 오브젝트까지 평평하게 넓힙니다. 그래서 오브젝트가 흙에 묻히지 않습니다.
- **땅깎기 / 흙쌓기**: 노반 바깥은 지형까지 `cutSlope`(1:1) / `fillSlope`(1:1.5) 비탈로 잇습니다.
- **터널**: 지면이 레일보다 `tunnels.cover`(15 m) 넘게 높고 `tunnels.minLength`(60 m) 넘게 이어지면 터널을 만듭니다. 갱구에는 아치 벽을 세우고, 안쪽에는 라이닝(반지름 `tunnels.radius` 5.5 m)을 깝니다. 갱구 자리의 지형에는 구멍을 냅니다. 역 승강장 구간에는 터널을 만들지 않습니다.
- **노선이 직접 그린 터널**: 블록에 파일 이름에 `tunnel`이나 `터널`이 들어간 오브젝트가 있으면 노선이 터널을 그린 것으로 봅니다. 이때는 지형만 터널 위를 덮고, 라이닝과 갱구는 만들지 않습니다.
- **교량**: 레일이 지면보다 `bridgeHeight`(12 m) 넘게 높으면 흙을 쌓지 않고 골짜기를 그대로 둡니다. 교량은 노선 오브젝트가 그립니다.
- **바다**: 표고 0 m 이하는 해수면 높이로 평평하게 만들고 물 색을 칠합니다.

자동 판정이 틀린 곳은 `zones`로 고칩니다. 마지막에 적용되며, 뒤에 적은 항목이 앞의 것을 덮습니다.

```json
"zones": [
  { "from": 1380, "to": 3920, "type": "open" },          // 터널이 아님
  { "from": 26120, "to": 28370, "type": "tunnel" },      // 터널 생성(라이닝·갱구 포함)
  { "from": 30000, "to": 30500, "type": "routeTunnel" }, // 노선이 그리는 터널: 지형만 덮음
  { "from": 41000, "to": 41300, "type": "bridge" }       // 골짜기 그대로
]
```

## 모든 설정

| 키 | 기본값 | 뜻 |
|---|---|---|
| `anchors[]` | (필수) | `track` 또는 `station`(번호·이름), `lat`, `lon`, 선택 `elevation` |
| `heading` | | 기준점이 하나일 때 그 지점의 선로 방위(도) |
| `dem` | AWS Terrain Tiles | Terrarium PNG 타일 주소. `{z}` `{x}` `{y}`가 들어간 URL이나 이 파일 기준 상대 경로(오프라인 타일 폴더) |
| `zoom` | 13 | 타일 확대 수준(8–15). 13이면 위도 37°에서 화소 하나가 약 15 m, 14면 약 7.6 m |
| `width` | 1500 | 선로 양쪽으로 지형을 만들 거리(m) |
| `verticalWindow` | 8000 | 높이 맞춤 중앙값 구간(m) |
| `formation.width` / `depth` / `objectWidth` | 8 / 0.5 / 60 | 노반 반폭, 레일 아래 깊이, 노반을 넓힐 오브젝트 최대 거리(m) |
| `formation.cutSlope` / `fillSlope` | 1.0 / 0.67 | 비탈 기울기(수평 1 m당 높이) |
| `bridgeHeight` | 12 | 이보다 높으면 흙을 쌓지 않음(m) |
| `tunnels.enabled` / `cover` / `minLength` / `radius` | true / 15 / 60 / 5.5 | 터널 생성 여부, 판정 토피, 최소 길이, 라이닝 반지름 |
| `zones[]` | | `from`, `to`(거리정 m), `type`(`open`, `tunnel`, `routeTunnel`, `bridge`) |
| `mesh.nearSpacing` / `farSpacing` / `nearDistance` | 4 / 16 / 300 | 선로 가까운 타일과 먼 타일의 격자 간격, 가까운 타일 기준 거리(m) |

## 렌더링

지형은 256 m 타일로 나뉩니다. 각 타일은 노선 블록에 놓인 오브젝트처럼 카메라 근처에서만 워커 스레드가 만들어 올리고, 멀어지면 내립니다. 그래서 긴 노선도 메모리를 많이 쓰지 않습니다. 선로에서 300 m 안의 타일은 4 m, 그 밖은 16 m 격자로 만들고, 타일 경계는 스커트로 틈을 가립니다. 그림자도 드리웁니다. 풀, 바위, 흙, 콘크리트 텍스처는 처음 실행할 때 절차적으로 만들어 캐시에 둡니다.

`ots_check --terrain <노선.csv> <terrain.json> [타일 수]`는 화면 없이 지형을 만들고, 정해진 표본 타일의 메시 생성 시간과 체크섬을 출력합니다(회귀·성능 확인용). 디버깅: `OTS_TERRAIN_DEBUG=1`이면 생성한 터널 목록과 몇 지점의 높이 계산을 로그로 남깁니다. `OTS_START_TRACK=<m>`은 열차를 그 거리정에 놓고 시작합니다.

## 표고 자료

기본 주소는 AWS Open Data의 [Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)(Terrarium 형식)입니다. SRTM, GMTED, ETOPO1, 각국 공개 DEM 등을 합친 자료이며, 출처 표기는 위 페이지의 안내를 따릅니다. 받은 타일은 캐시에만 두고 배포하지 않습니다.
