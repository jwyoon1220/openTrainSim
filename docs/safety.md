# 내장 열차방호장치 (safety.json)

openTrainSim은 한국 철도의 열차방호장치를 시뮬레이터 안에 내장합니다. openBVE 플러그인(`ats.cfg`)이 없어도 동작하고, 리눅스에서 Mono도 필요 없습니다.

| 장치 | 쓰는 곳 | 하는 일 |
|---|---|---|
| **ATS** | 일반선 (코레일 지상자 점제어식) | 신호기를 지날 때 받은 코드의 조사 속도를 감시합니다. 속도를 넘으면 경보가 울리고, 확인하지 않으면 비상제동을 겁니다. 정지신호를 지나면 즉시 비상제동합니다. |
| **TVM430** | 고속선 (KTX) | 폐색마다 속도 단계(300/270/230/170/80/000)를 연속으로 받고 다음 폐색 단계를 예고합니다. 단계를 일정 이상 넘으면 비상제동합니다. |
| **ATP** | 한국형 ATP (ETCS Level 1 기반) | 신호기 발리스에서 이동권한과 속도 프로파일을 받아 제동곡선으로 감시합니다. 경고 → 상용제동 개입 → 비상제동 개입 순입니다. 이동권한 끝을 넘으면 트립(TR), 이후에는 SR 모드로 운전합니다. |

## 지상설비는 자동입니다

노선 작성자가 비콘(`Track.Beacon`) 번호를 플러그인 규약에 맞춰 깔 필요가 없습니다. 지상설비 정보는 시뮬레이터가 아는 **폐색 구간 점유와 현시**에서 만듭니다.

- **ATS 코드**: 신호기를 지날 때 그 신호기의 현시입니다. 현시 번호 → 코드 대응은 열차 설정에서 바꿉니다.
- **TVM 단계**: 지금 폐색 앞쪽에 비어 있는 폐색 수로 정합니다. 앞 폐색이 점유되면 000, 하나 비면 80, …
- **ATP 이동권한**: 앞쪽 첫 번째 정지 현시 신호까지입니다. 속도 프로파일은 노선 속도 제한에서 만듭니다.

다른 열차(`traffic.json`)가 폐색을 점유하면 현시가 바뀌고, 보안장치도 그대로 반응합니다.

어느 구간에 어떤 장치가 깔려 있는지는 자체 노선 형식의 `"safety"` 구역으로 적습니다([route-format.md](route-format.md)). openBVE 노선처럼 구역이 없으면 열차 설정의 `default` 장치를 씁니다.

## 열차 설정: `<열차 폴더>/safety.json`

```jsonc
{
  "systems": ["ats", "atp", "tvm430"],  // 차상장치 (이 열차가 가진 것)
  "default": "ats",                     // 노선에 구역이 없을 때
  "transitionAckSeconds": 8,            // 다른 장치 구역에 들어간 뒤 확인 제한시간
  "ats": {
    "ackSeconds": 3,                    // 속도초과 경보 후 확인 제한시간
    "toleranceKmh": 1,
    "minBrake": 1,                      // 확인 후 속도가 내려갈 때까지 유지할 제동 노치
    "afterStopKmh": 15,                 // 정지신호 통과 비상제동을 푼 뒤 다음 신호까지 제한 속도
    "codes": [                          // 이름, 조사 속도(없으면 무제한), stop = 지나면 비상제동
      { "name": "R0", "kmh": 0, "stop": true },
      { "name": "YY", "kmh": 25 }, { "name": "Y", "kmh": 45 }, { "name": "YG", "kmh": 65 },
      { "name": "G" }
    ],
    "aspects": { "0": "R0", "1": "YY", "2": "Y", "3": "YG", "4": "G" },  // 노선 현시 번호 → 코드
    "clear": "G"                        // 목록에 없는 현시
  },
  "tvm430": {
    "steps": [300, 270, 230, 170, 80, 0], // 빠른 것부터, 마지막은 000
    "warningMarginKmh": 5,              // 단계 + 이만큼: 경보
    "emergencyMarginKmh": 15,           // 단계 + 이만큼: 비상제동 (단계 아래로 내려가면 풀림)
    "finalDecel": 0.6                   // 000 폐색 끝까지의 제동곡선 감속도 (m/s²)
  },
  "atp": {
    "serviceDecel": 0, "emergencyDecel": 0, // m/s², 0이면 train.dat 감속도의 80% / 110%
    "brakeDelay": 1.5,                  // 제동이 듣기까지 (초)
    "indicationTime": 4,                // 상용제동 곡선보다 먼저 경고하는 시간 (초)
    "releaseSpeedKmh": 15,              // 이동권한 끝 근처에서 허용하는 속도
    "ceilingWarningKmh": 3, "ceilingServiceKmh": 6, "ceilingEmergencyKmh": 10, // 선로 최고속도 여유
    "staffResponsibleKmh": 40,          // 트립 후 SR 모드 제한 속도
    "lookahead": 8000                   // 받는 속도 프로파일 길이 (m)
  }
}
```

모든 항목은 생략할 수 있고, 생략하면 기본값을 씁니다. `safety.json`이 아예 없으면 ATS 하나만 있는 것으로 봅니다(`[simulation] safety = builtin`일 때). 기본 코드와 속도는 흔히 알려진 값입니다. 실제 규정 값과 다르면 이 파일에서 맞춥니다.

## 플러그인과의 선택

`openTrainSim.cfg`의 `[simulation] safety`로 정합니다.

| 값 | 동작 |
|---|---|
| `auto` (기본) | 열차 폴더에 `safety.json`이 있으면 내장 장치, 없으면 `ats.cfg` 플러그인 |
| `builtin` | 항상 내장 장치 (`safety.json`이 없으면 ATS 기본값) |
| `plugin` | 항상 플러그인 |

## 운전

- **확인 버튼**: openBVE `SECURITY_S` 명령입니다(기본 키 Space). 속도초과 경보 확인, 장치 전환 확인, 정차 후 비상제동 복귀에 씁니다.
- **장치 전환**: 다른 장치 구역에 들어가면 새 장치가 바로 감시를 시작하고 확인을 요구합니다. `transitionAckSeconds` 안에 확인하지 않으면 상용제동이 걸립니다.
- **DMI**: 화면 왼쪽 아래에 표시합니다. 원형 속도계에 허용 속도까지 회색, 넘으면 빨간 띠, 개입 속도는 주황으로 나옵니다. 받은 코드(ATS 현시, TVM 단계, ATP 모드), 목표 속도와 거리 막대, 경고 문구, 확인 요청도 함께 나옵니다.
- **경보음**: 운전실에서 합성합니다. 속도초과 경보는 끊어지는 삑 소리, 제동 개입은 두 음이 번갈아 나는 소리, 확인 요청은 부드러운 차임입니다.

## 운전실 연결: `safety[n]`

`cab.json`과 `panel.animated`의 함수식에서 쓸 수 있습니다(`pluginState[n]`과 같은 방식).

| n | 값 |
|---|---|
| 0 | 활성 장치: 0 없음, 1 ATS, 2 TVM430, 3 ATP |
| 1 | 허용 속도 (km/h, 없으면 -1) |
| 2 | 목표 속도 (km/h, 없으면 -1) |
| 3 | 목표까지 거리 (m, 없으면 -1) |
| 4 | 경보 중 (0/1) |
| 5 | 제동 개입 중 (0/1) |
| 6 | 비상제동 (0/1) |
| 7 | 확인 요청 (0/1) |
| 8 | 개입 속도 (km/h, 없으면 -1) |
| 9 | 코드: ATS 코드 번호(`codes` 순서), TVM 단계 km/h(000은 0, RRR은 -1), ATP 모드(0 FS, 1 SR, 2 TR) |

예: TVM 단계 표시창 숫자 `safety[9]`, 경보 램프 `if[safety[4] | safety[5], 1, 0]`.

## 시험

화면 없이 시나리오를 돌려 개입 기록을 출력합니다.

```
ots_check --safety examples/routes/safety-test.route.json examples/trains/test-emu obey examples/routes/safety-test.traffic.json
```

| 시나리오 | 운전자 | 기대 결과 |
|---|---|---|
| `obey` | 선로·코드·신호 속도와 예고를 지킴 | 개입 0회 |
| `ack` | 신호 속도를 무시하지만 경보에 확인하고 제동 | 경보만, 신호 위반 시 개입 |
| `ignore` | 신호 속도를 무시하고 확인하지 않음 | 경보 → 비상제동 |
| `redpass` | 속도는 지키지만 정지신호에서 서지 않음 | 정지신호 통과 비상제동 → 15 km/h 제한 운전 |

느린 선행 열차로 정지신호를 만나는 시험은 `examples/routes/safety-test-close.traffic.json`을 씁니다.
