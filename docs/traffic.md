# 다른 열차 (AI 열차, traffic.json)

노선에 내 열차 말고도 여러 열차를 넣을 수 있습니다. 모든 열차는 같은 폐색 구간을 공유합니다. 앞 열차가 있는 구간은 정지 현시가 되고, 그 뒤 구간은 차례로 주의·감속·진행 현시가 됩니다. 내 열차의 보안장치 플러그인(ATP/TVM 등)도 앞 열차 때문에 바뀐 현시를 받습니다.

## 열차를 넣는 방법

1. **노선의 `Route.RunInterval`(= `Train.Interval`)**: openBVE와 같습니다. 값마다 내 열차와 같은 차종의 선행 열차가 하나씩 생깁니다. `Route.RunInterval 300; 900`이면 5분 앞, 15분 앞에 열차가 있습니다. 음수는 openTrainSim 확장으로, 그만큼 뒤에 출발하는 후속 열차입니다.
2. **`<노선 파일 이름>.traffic.json`**: 노선 파일 옆에 두면 자동으로 읽습니다(예: `KTX123.csv` → `KTX123.traffic.json`). `--traffic <파일>`로 직접 지정할 수도 있고, `--traffic none`이나 설정 파일의 `[simulation] traffic = 0`으로 끕니다.

```json
{
  // 노선의 Route.RunInterval도 함께 쓸지 (기본 true)
  "routeIntervals": true,
  "trains": [
    { "name": "앞 KTX", "interval": 300 },                         // 5분 앞서 같은 시간표로 운행
    { "name": "뒤 KTX", "interval": -600 },                        // 10분 뒤 출발
    { "name": "새마을", "train": "../../Train/Saemaeul",           // 다른 차종 (이 파일 기준 상대 경로)
      "departure": "09:40:00", "station": 3,                       // 3번 역에서 09:40 출발
      "maxSpeed": 150, "stops": false }                            // 최고 150 km/h, 모든 역 통과
  ]
}
```

| 키 | 뜻 |
|---|---|
| `name` | 로그와 디버그 출력에 쓰는 이름 |
| `train` | 열차 폴더. 없으면 내 열차와 같은 차종 |
| `interval` | 시간표를 몇 초 앞당겨(양수, 선행) 또는 늦춰(음수, 후속) 운행할지 |
| `departure` | `interval` 대신 쓰는 출발 시각(`HH:MM:SS`, `HH:MM`, openBVE식 `HH.MMSS`). 이후 역 시각도 같은 만큼 옮겨집니다 |
| `station` | 출발역 번호(0부터). 없으면 내 열차의 출발역 |
| `maxSpeed` | 최고 속도(km/h) |
| `stops` | `false`면 정차하지 않고 통과 |
| `dwell` | 최소 정차 시간(초). 없으면 역마다 `Sta`의 정차 시간 |

## 동작

- **선행 열차**: 게임을 시작하기 전에 출발 시각부터 지금까지 미리 달려서, 지금 있어야 할 위치에 놓입니다. 간격이 정차 시간보다 짧아 아직 출발역에 서 있으면 내 열차 뒤로 들어옵니다.
- **후속 열차**: 출발 시각이 되고 출발역 승강장이 비면 나타납니다.
- **운전**: 노선 속도 제한과 `Route.Signal` 신호 속도를 지킵니다. 정지 신호 앞, 정차역 정지 위치, 다른 열차 뒤에서는 제동 곡선을 따라 섭니다. 역에서는 문을 열고 정차 시간과 출발 시각(옮겨진 시간표)을 지킨 뒤 문을 닫고 출발합니다. 출발 신호가 정지 현시면 기다립니다.
- **종착**: 종착역에서 정차를 마치거나 노선 끝에 닿으면 사라집니다.
- **충돌**: 신호를 무시하고 앞 열차에 닿으면 그 자리에서 멈춥니다(로그에 `Collision`이 남습니다).

## 제약

- 모든 열차는 0번 선로를 같은 방향으로 달립니다. 반대 방향 열차, 다른 선로로 비켜 가는 열차(대피, 추월)는 아직 없습니다.
- AI 열차는 소리를 내지 않고, 보안장치 플러그인도 돌리지 않습니다.
- 값 방식 구간(`Options.SectionBehavior 1`)만 쓰고 정지 현시(0)가 없는 노선에서는 신호가 앞 열차를 막지 못합니다. 이때도 AI 열차는 앞 열차와 거리를 두지만, 내 열차는 운전자(또는 플러그인)가 지켜야 합니다.

## 시험

`ots_check --traffic <노선.csv> <열차 폴더> <traffic.json> [분] [stay|drive]`는 화면 없이 열차들을 돌리고 1분마다 위치, 속도, 노치, 정차역을 찍습니다. `drive`면 내 열차도 단순 자동운전으로 달립니다. 환경변수 `OTS_TRAFFIC_TRACE=1`을 주면 AI 열차가 서 있는 이유(목표 속도, 신호, 다음 정차역)를 로그로 남깁니다.
